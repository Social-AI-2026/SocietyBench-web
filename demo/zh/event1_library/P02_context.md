# 机构K案件C

> 当事人姓名锚定（据一审判决书）：涉事男生真名为**人物A**（机构U2022级本科生，官方通报中作"人物A/人物A"）；涉事女生真名为**人物B**（机构V世界经济专业硕士研究生，官方通报中作"人物B/人物B/人物B"）。下文沿用各来源原始称谓，二者均指上述同一当事人。

## 全部进展

### 2023-07-01

**事件**：机构K于6月30日针对网络曝光的案件C发布情况说明，确认已关注到学生举报遭受性骚扰的网络信息并成立工作组展开调查。该校机构U院长同日向媒体回应称学院正在调查事实真相。机构A于6月30日接警介入此事。7月1日，有网友披露涉事男生系2022年以"外语类保送生"身份保送至机构K，该校机构W工作人员当日对此回应称暂时不方便透露相关信息，强调学校正在调查此事。截至目前，校方尚未公布调查结论。

**舆论**：舆论场呈现剧烈反转态势，主流观点从最初支持女方"勇敢发声"转向压倒性同情涉事男生、质疑"诬告"，大量网民以"败诉""证据不足""监控未看"等细节为据，认定女方"小作文维权"系网络暴力，要求其道歉并承担法律责任。情绪以愤怒、嘲讽为主导，"一眼看穿性别""全员恶人"等梗弥漫，折射出公众对多次反转事件的疲惫与对司法判决的倚重。争议焦点集中于"隔着裤子"行为能否构成性骚扰、手写道歉信效力、以及网络曝光是否替代法律程序，同时穿插对潦草字迹的调侃与对媒体"网暴"报道的批评。性别对立情绪显著，部分声音主张男方反诉诬陷，亦有少数坚持处分过轻，但整体信任已向"程序正义"倾斜。

### 2023-07-02

**事件**：官员A于7月2日上午就网络传言作出公开回应，澄清其2013年结婚、2014年出生的儿子目前仍在小学就读，与机构K案件C涉事男生毫无关联。官员A同时否认其父亲为公司A前负责人的说法，表示父亲系地区B当地人士，已于十余年前去世，生前工作从未离开地区B范围。官员A称该谣言对其及家人造成重大伤害，已选择报警处理并通过媒体发布书面声明。机构K于7月2日晚发布通报，确认2022级本科生人物A在图书馆对女生实施性骚扰行为属实，依据校规给予记过处分。受害女生曾于3月在图书馆遭遇性骚扰，事后多次与辅导员沟通协商未果，三个月后发文网络引发舆论关注，校方于6月30日深夜成立工作组，仅用三天作出处分决定。

**舆论**：舆论场呈现明显的两极分化与后续反转态势。主流声音从最初部分支持女方"勇敢发声"，转向压倒性质疑指控真实性，大量网民为涉事男生辩护，认定其"被诬告""明明是挠痒"，要求女方道歉并承担法律责任；同时存在对校方处分过轻的批评，认为对比作弊开除案例，记过处罚过当。情绪以愤怒、嘲讽为主，夹杂对"小作文维权"模式的疲惫与反思，"败诉""证据不足""监控未看"成为高频关键词，"一眼看穿性别""全员恶人"等表述凸显性别对立张力。争议焦点集中于证据效力（潦草道歉信、隔裤行为界定）、程序正义（为何网络曝光而非立即报警）、以及媒体责任（媒体A被批信息模糊、"网暴"）。此外，副区长辟谣衍生出地域调侃与谣言猎奇性讨论，手写道歉信字迹潦草意外成为吐槽热点，反映舆论对核心议题的偏离与娱乐化解构倾向。
