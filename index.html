Society-Bench

Can Language Models Forecast Real-World Social Events?_

▸ Paper (PDF) ▸ arXiv ▸ Code ▸ Dataset SOON ▸ Video ▸ BibTeX

Abstract

We present the first benchmark capable of measuring the ability to forecast real-world social events using anonymized ground truth from Web news and social-media.

Our approach collects Web news and social-media posts across five platforms, distills each source into date-indexed timelines via a six-step agent-driven processing chain, and merges them into a unified chronology that separates factual events from public opinion. We apply an anonymization procedure that renders each real event arc into a counterfactual social world, ensuring the evaluation measures forecasting ability rather than the ability to search for the real event. We then automatically generate an agent-audited question bank supporting two orthogonal evaluation axes: probability calibration and temporal accuracy.

Key Contributions

01

Counterfactual Anonymization

Three-phase entity-and-date anonymization (rule replacement → LLM adversarial audit loop, ≤ 5 rounds, stops at high = 0 and mid = 0 → consistency check). Renders each real arc into a deidentified counterfactual world — structurally identical, stripped of pre-training-matchable surface labels.

02

Dual-Axis Scoring

Two orthogonal 0–100 scores per event: Calibration (weighted MAE against binary ground truth, vs. a uniform 50% predictor) and Temporal accuracy (day-MAE vs. a 30-day bucket-midpoint baseline). A model can be well-calibrated but date-blind, or vice versa; both are reported.

03

Dual-Source Timelines

Per event, the pipeline collects in parallel Web news + five social-media platforms, and merges them into a unified chronology that explicitly separates factual events from a public-opinion layer — measuring social dynamics, not just news facts.

Method

Four-Phase Pipeline

Our benchmark operates through a four-phase pipeline: collecting multi-source data, distilling timelines, merging and anonymizing them into counterfactual worlds, and evaluating models on probability calibration and temporal accuracy.

Phase What it does
00Collection Collects Web news and social-media posts across five platforms
01Per-source Distills each source into date-indexed timelines
02Merge Merges streams into unified chronology separating facts from opinion
03Evaluation Anonymizes, generates questions, and scores on two axes

Three-Phase Anonymization

The anonymization pipeline renders each merged timeline into a counterfactual world before any candidate model sees it. The auditor loop stops at high = 0 and mid = 0, max 5 rounds.

01

Rule-based Replacement

Replace entities by longest-match against a per-event substitution table; shift every date uniformly by a single offset δ ~ U(±180 d), destroying absolute calendar position while preserving every inter-event gap.

02

LLM Adversarial Audit Loop

An auditor LLM reads the anonymized text and reports residual search-key leakage (high) and substitution-quality issues (mid). New replacement rules are auto-derived from findings and Phase 01 re-runs from the raw original. Loop stops at high = 0 and mid = 0, max 5 rounds.

03

Consistency Check

Paragraph-, event-, and narrative-level comparison against the original, repairing any substitution damage while preserving anonymized entities and shifted dates.

Dual-Axis Evaluation

At each accepted prediction point, the candidate sees the context up to a cutoff date and answers two orthogonal question types.

AXIS 01 — CALIBRATION

Probability Calibration.

For an event E in a time window W, the model outputs P(E occurs in W) ∈ [0,1]. Scored by weighted MAE against binary ground truth.

0 uniform 50% 100 perfect predictor
AXIS 02 — TEMPORAL

Temporal Accuracy.

For each in-window event, predict its calendar date. Scored by day-MAE against a 30-day bucket-midpoint baseline.

50 bucket-midpoint baseline 100 perfect timing

Contribute

Everything you submit is reviewed and added to the public leaderboard.

01

Bring Your Model

Run our 5 events on your LLM or agent, submit your scorecard via PR. The team replays your raw answers with our scoring code — no honor system.

Submission guide → 
WHAT TO SUBMIT  (place in submissions/<your-name>/<model-name>/)
  ▸ model_card.md         — name, version, params, training cutoff
  ▸ predictions.jsonl     — one line per question: {point_id, q_id, p_hat or d_hat}
  ▸ run_metadata.json     — reasoning depth, decoding params, API provider, dates
  ▸ scorecard.json        — scores computed by /eval/predict_step4_scorecard.py

PROCESS
  01  Clone the repo, read README quickstart
  02  Run `python main.py --model <your-model> --workspace ./run_<your-model>`
  03  Verify your scorecard matches what the script computed
  04  Open a PR with the four files above

The team replays your raw answers with our official scoring code.

02

Bring a New Event

Use our public pipeline (web-crawl → media-crawl → merge → anonymize → questionbank) to construct a new anonymized event. Submit it via PR; if accepted it joins the official 5+.

Pipeline guide → 
WHAT TO SUBMIT  (place in submissions/<your-name>/event-<slug>/)
  ▸ event_meta.json       — slug, domain, arc dates, source platforms
  ▸ timeline_anon.md      — final anonymized timeline
  ▸ replacements.json     — substitution table (for audit)
  ▸ questionbank/*.json   — per prediction point
  ▸ gt/*.md               — per prediction point
  ▸ audit_report.json     — Phase 2 must show high=0 and mid=0

PROCESS
  01  Use `eval/total_pipeline.py` to crawl + process + anonymize your event
  02  Verify the anonymization audit converges (high=0, mid=0)
  03  Open a PR adding the event folder

Accepted events join the official catalog and ship in the next benchmark version.

Deep Dive

Five tables behind the headline number. Stress cases isolate where models break; four ablations isolate where the benchmark's difficulty comes from.

Qualitative

A single anonymized geopolitical prediction point (Day 22 cutoff). The same point queried twice — once for calibration probability, once for temporal date — across four candidates: the strongest LLM, two LLMs that bracket the dominant failure modes (near-term over-extension, uniform-collapse), and the strongest projected agent setup.

Naval drill positioning combined with escalating rhetoric across Days 22–29 indicates intent; absence of public de-escalation channels makes a kinetic response within 14 days likely.

P̂ = 0.78 · GT: strike occurred Day 31 (within window) · CALIBRATED

Signals point in opposing directions; insufficient basis to deviate from the prior.

Limitations

  • Censored social-media signal. The Chinese social-media layer is censored and platform-curated; the opinion layer measures "opinion as visible on platform," not ground-truth population sentiment.
  • Forecasting-only scoring. The two scoring lines target forecasting; an LLM-as-judge quality axis (narrative coherence, justification rigor) is excluded for now.
  • Five events is a small sample. Per-event scores are released alongside the mean so a single long-horizon event cannot silently dominate cross-event conclusions; multi-event evaluation is strongly motivated.
